Msgboard test audit

17 November 2026 · Cleanup PR #41

197.45 → 167.66 seconds (15.1% shorter). 299 → 255 runnable cases; 233 → 232 test functions. All 47 invalid inputs retained. No production code changes.

Baseline main: f18b671. Cleanup: a4798ef. Same interpreter, host and sequential command: python -m pytest -q --durations=0 --durations-min=0 --junitxml=.... Both pass; the existing opt-in live test remains excluded. These are single local runs and are not a production benchmark.

What was trimmed

  • tests/test_analytics.py: 11 invalid ranges on one board; all 11 requests retained.
  • tests/test_auth.py: 6 invalid invites on one board; all 6 requests retained.
  • tests/test_tasks.py: 8 malformed block inputs on one board; rejected state checked each time.
  • tests/test_guest_storage_links.py: 12 nonsharing references on one board; all 12 access denials retained.
  • tests/test_transfer.py: 10 corrupt bundles reuse one source/destination pair; fresh bundle data and rollback assertions for every input.
  • tests/test_channel_queries.py: Remove superseded empty-channel query guard and one-channel variant; keep mixed 100-channel count/permission data and ≤8 query assertion.
  • tests/test_replicate.py: 4 explicit snapshots replace 8 timed snapshots; keep 3 and verify latest remains present.

The five invalid-input lists avoid 51 real board instances. They still check each rejected input; corrupt imports start from fresh bundle data every time. AGENTS.md asks contributors to reuse existing behavior tests and avoid unnecessary sleeps or full-suite reruns.

Why the rest stays

Distinct role permissions, public/private channel access, DM totals, revoked file links, atomic task answers, import rollback, concurrent writes, migrations, SIGKILL/SIGTERM durability and handover have different failure modes. No such checks were dropped, mocked or moved out of the default suite. The 10-second runaway-query cutoff still verifies the real production limit; the 8,000-message search and 1,200-thread analytics regressions still exercise large inputs.

Times include pytest setup, call and teardown, rounded separately; process startup and collection account for the remaining wall time. File timing differences are noisy and should not each be treated as a measured improvement.

Limits of this cleanup

The reduction is in duplicate setup and obsolete waiting, rather than an arbitrary target test count. The retained suite still takes about 2 minutes 48 seconds on this host. Shared invalid-input lists stop at their first failed assertion, whose message identifies the failing input. Permission matrices and different starting states remain independently isolated.
