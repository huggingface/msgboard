MSGBOARD - PR #57 - BUG FIX

HIDE IDLE SCROLLBARS WHILE READING A PANE

1

INTRODUCTION.

Hovering anywhere in a pane, or clicking a control inside it, kept its scrollbar visible. The thumb now hides after scrolling stops, while the gutter and native scrolling stay in place.

2

HOW IT WORKS.

1. Scroll events arm the timer; pointer and geometry changes refresh edge proximity. Document exit clears the cached pointer even without blur. 2. Keyboard focus on buttons and checkboxes reveals the thumb; editable fields do not keep it painted.

2.1

Browser boundaries.

Standard colors and legacy WebKit rules stay separate. Both window resize and pane observation refresh edges. The gutter stays reserved, keeping the message width and reading position steady.

3

VALIDATION.

Two existing browser tests pass in 63.81 s. Native thumb drags use stored scroll positions. Checks cover idle-before-edge, checkbox focus, Settings, search, resize and reading positions. Earlier real X11 exit evidence is retained.
