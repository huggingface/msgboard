1

INTRODUCTION.

Administrators copy one public channel as a verified ZIP. The target keeps original authors, timestamps, threads, reactions, the current doc and linked files. Imported history stays searchable and quiet. Apply reuses the reviewed ZIP.

2

HOW IT WORKS.

(1) Export captures one database snapshot, then verifies copied bytes. (2) Import checks bytes and target file conflicts, then maps handles; missing authors become disabled ghosts. (3) Bucket I/O runs outside the writer under path reservations. Short SQL steps prepare ghost IDs, then recheck and publish metadata.

2.1 Replay and read state.

The target records the manifest digest. Exact retries create nothing; a changed snapshot is refused. History flags exclude these rows from activity, mention creation and unread counts.
