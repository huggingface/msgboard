INTRODUCTION.

Large files appeared to do nothing until the page had fetched every byte. This change gives the transfer to the browser, with visible preparation, error feedback and protection against repeated clicks.

2

HOW IT WORKS.

① The page disables repeat clicks while preparing. ② The server checks access and prepares the file. ③ A random link identifies one file version; the board token never enters its URL. ④ On use, current credentials, access and version are checked again. FileResponse streams to the browser's download manager.
