MSGBOARD - PR #2 - BUG FIX
MOBILE ENTER INSERTS A NEWLINE
KEY
DASHBOARD INPUT - KEYBOARD CONTROL
1

INTRODUCTION.

On phones and tablets, Enter inserts a newline instead of sending a message or saving an edit. The existing Send and Save buttons perform those actions. Desktop keyboard shortcuts continue to work.

2

HOW IT WORKS.

(1) Each Enter checks the current viewport and primary pointer. (2) Mobile handlers return before sending, saving or choosing a mention. The browser inserts the line break. Channel, DM and thread composers share this path.

2.1

Native text entry.

No synthetic newline is inserted. The textarea retains browser caret, selection and composition behavior.
